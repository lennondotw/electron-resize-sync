# Work log

Date: 2026-09-23

## Completed

- Built the toolchain step by step, each step runnable: pnpm, TypeScript 7
  (`af86e28`), Vite and React (`9c99134`), Tailwind CSS v4 (`d2fa622`), oxlint
  (`c4b349f`), oxfmt and `pnpm check` (`0d8355b`), Electron with a Vite-driven
  dev loop (`7a78bbb`).
- Janky renderer (`1f3fb7e`): a rAF loop that blocks the main thread for a
  configurable busy budget each frame and re-renders a grid of tiles. `<html>`
  and the native window use `--canvas`; `#root` uses a slightly different
  `--surface` grey in both light and dark, so exposed background is visible.
- Frame-rate-independent tile wave (`325422b`), calmer animation (`e949d16`),
  OKLCH colour interpolation (`a7312c6`).
- Transparent macOS title bar with a draggable in-app title area; the tile
  background runs under it (`33ffaab`).
- HUD: Base UI slider (`05fa5a8`), estimated max fps from the busy budget
  (`49247b9`, `2d064db`, `e15d2b8`); fixed a negative fps from the first rAF
  delta (`52bb339`).
- Tiles fit the window whole, with equal gaps and even padding (`16f61ab`,
  `9c5ef57`). Window 760×480 by default, 480×360 minimum (`eb539b0`).
- Renamed the project to electron-resize-sync (`c495c5e`).

## Validation

- `pnpm check` and `pnpm build` after each step.
- Ad hoc CDP checks against the built app: about 16 fps with 60 ms busy work;
  `<html>` and `#root` computed colours differ as intended in both schemes.
  These checks predate the experiment scripts; the frame rate per budget is
  now recorded by the [resize pacing run](../experiments/2026-09-24/resize-pacing/README.md).
